New `@agentaos/nextjs`: a `Checkout` route that redirects to a checkout for one of your products, and a `Webhooks` route that verifies deliveries and calls one handler per event. `@agentaos/pay` exports `WebhooksResource`, so webhooks can be verified without an API key.
